# 天之灵声音训练工作流交接记录

更新时间：2026-09-01

这是声音训练业务的唯一长期交接文档。以后修改声音素材、AI 剪辑、片段审核、模型训练、试听、声音套餐或小使者交互前，先读本文；修改完成后同步更新本文。

## 一、已确认的产品原则

1. 小使者在这里是温暖、克制、可信的客服和流程向导，不是假装亲友本人。
2. 页面沿用创建天之灵的“小使者 + 核心内容 + 阶段操作”形式，不做连续聊天气泡列表。
3. 小使者用文字和女性语音表达；文字和语音来自同一份文案，按阶段换行展示。流程中的固定阶段文案和语音必须随声音训练子包预置，页面打开或阶段变化时直接播放本地音频，不得临时调用语音生成；只有用户主动提问后的动态回答可以实时生成。语音失败不能阻塞页面操作。音色生成完成页需要明确提醒：受大模型厂家限制，生成音色暂存 7 天，7 天内未使用会由厂家自动清理。
4. 声音训练免费。只有用户实际启用声音服务时才提示购买；训练流程不选择套餐。
5. 有声音服务的会员通常比无声音服务的会员贵，但价格会变化。用户询价时读取当前有效会员计划，并介绍一年价格，以会员服务页最新展示为准。
6. 声音素材只有两个添加入口：从微信聊天选择音频、视频等文件，或从手机相册选择录屏和视频。微信原生语音消息不能直接导入；用户需要先播放语音并录屏，录屏视频保存到手机相册后再从相册选择。支持一次添加多份，单文件不超过 50MB。
7. 上传和提交必须分开。当前素材上传或保存时仍允许用户继续选择下一份，新增素材进入串行上传队列；上传成功后仍保留“继续添加素材”和明确的提交按钮，因为系统不能代替用户判断是否全部传完。
8. AI 负责按说话人、完整语句、清晰度整理候选片段；用户选中任意一个或多个“可以使用”的片段后即可开始训练，不要求处理完全部候选，仍为待确认的片段不参与本次训练。审核页引导用户精选 1 分钟以内，声音不是越多越好；新客户端阻止继续超选，旧客户端超选时后端按质量分择优取 1 分钟。
9. 用户也可以选择“素材已经剪好，直接使用”，此时不做 AI 语句切分，只统一训练格式并让用户试听确认。
10. 当前 Qwen 音色创建按单个训练音频提交。多个已确认片段先在服务端合并成一个 WAV，再创建声音模型。
11. 用户可以从“识别剪辑中”或“试听剪辑结果”返回素材准备。已上传素材必须保留，旧剪辑结果作废，晚到的后台结果不能把流程推回审核页。
12. 界面文案统一使用“他”，不要出现“TA”或“Ta”。
13. 用户可以永久删除单份原始素材，也可以一次删除当前会话的原始素材、分析临时音频、审核切片、训练合并音频、试听音频和声音模型。整包删除同时解除天之灵的声音绑定；实物数据删除，业务记录保留删除状态、时间、失败明细和事件用于审计与重试。
14. 候选片段先检测最低时长、静音、音量、削波和背景噪声，再生成审核音频。明显不可用的片段提前排除并向用户展示指标和原因；可恢复的低音量片段自动调高后继续交给用户试听，系统不能代替用户做最终判断。
15. 声音使用资格按用户历史权益统一识别，不按旧履约任务是否已经创建或是否已经添加音色来限制。有效证据包括：购买过声音版会员、单独购买过声音服务、管理端创建过声音订单、非退款的历史声音训练任务、声音模型权益或已有后台音色绑定。退款记录不授予新接入资格。声音版会员完成部分退款并降级为基础版后，该降级记录优先于更早的会员、训练任务和绑定记录；独立购买的声音服务或降级后新购的声音版会员仍可授予资格。
16. 已有声音资格的用户可把训练音色接入多个属于自己的天之灵，不消耗次数；未购买用户仍可免费训练、试听和先选使用对象，购买后再次进入页面自动接入。目标天之灵已经绑定另一套后台声音时必须保留原服务，不得静默覆盖；后续如需替换，应增加明确的二次确认流程。
17. 用户选择“再剪一下”时必须填写具体剪法。该片段进入独立返工任务，其他片段及其审核结果不受影响；返工期间原片段保留，成功后原位替换并回到待确认状态，失败时展示原因并允许重新填写。当前自动返工支持明确时间描述，例如“去掉开头 2 秒”“只保留 3 秒到 8 秒”；无法定位的描述在入队前直接提示改写。
18. 每个用户都有独立音色仓库。训练完成的音色默认长期保留，新训练不能覆盖旧音色；只有用户明确永久删除时才删除平台音色、训练音频、试听音频和该音色生成的语音并解除绑定，原素材和审核切片继续按各自删除入口管理。当前阿里云百炼 Qwen-TTS 规则为：平台账号最多 1000 个 Qwen-TTS 自定义音色，达到上限不会自动淘汰旧音色；单个音色连续 1 年未用于语音合成时会被自动清理。平台记录每次真实合成并在预计清理前 30 天自动做一次短文本保活，用户页面必须说明服务商、清理条件、自动保留和主动删除后果。官方规则：[声音复刻](https://help.aliyun.com/zh/model-studio/voice-cloning-user-guide)。
19. 用户点击仓库中的音色进入信息页，可以查看并下载实际用于训练的片段和合并训练音频，调整之后输出的说话速度与音量，并用最多 100 字自定义文本生成、试听和下载语音。每个用户的全部音色合计每天最多成功生成 5 次，按北京时间自然日重置，切换或删除音色不能增加当天额度；服务商生成或保存失败时退回本次额度。当前 Qwen3-TTS-VC HTTP 模型不提供原生速度和音量参数，已训练音色又与创建时模型绑定，因此保持原模型合成，再由平台 FFmpeg 输出层调整速度和音量；速度范围 `0.5–2.0`，音量范围 `0.25–2.0`。
20. 声音模型入口按用户是否拥有已完成音色分流：没有完成过音色时，不展示空仓库，直接进入训练素材准备或恢复未完成流程；已有完成音色时进入“我的音色”。训练流程起点为已有音色用户提供紧凑的“我的音色”入口。用户从仓库选择“训练新音色”或重新进入已完成的训练流程时，新建一条 `collecting` 会话；上传、剪辑、审核、训练或失败中的会话继续原进度，不得被新会话覆盖。
21. 已绑定可用音色的天之灵在单个回复气泡达到 55 字时，优先把整轮回复生成为一条语音消息；语音合成或保存失败时仍发送原文字，不能阻塞聊天。聊天语音保存到对象存储，并在同一条消息记录音频键、时长和对应文字。用户长按语音可切换成文字，长按文字可切回语音；切换只改变消息展示类型，不删除已保存音频，也不重复合成。
22. 音色信息页不展示声音技术服务商，把首屏重点放在可编辑音色名称和“关联天之灵”。智能体主页为所有者增加“声音模型”：有完成音色时选择当前账户音色，没有时提示并进入训练。用户可在购买前先保存选择，但只有声音版会员或兼容的历史声音权益有效时才写入聊天实际使用字段；权益失效时保留为待生效选择并清除聊天使用字段。更换已生效或待生效的其他音色都必须二次确认。
23. 账号注销前，声音会话处于剪辑、训练或片段返工中时必须阻止注销。允许注销后复用现有声音数据删除编排，删除素材、切片、训练音频、试听、供应商模型并解除绑定；声音会话、任务标识、事件、删除状态和失败明细继续作为受限业务记录保留。账号注销服务不得改写管理端订单履约或已经接好的声音服务规则，部分删除失败由独立注销清理队列重试。

### 管理端豆包 Seed ICL 2.0 接入（2026-08-26）

- 管理端新增可选供应商“豆包 Seed ICL 2.0”，不改变现有 MiniMax、CosyVoice、Qwen 配置，也不改变小程序用户自助训练仍默认使用 Qwen 的流程。
- 创建豆包音色时必须填写火山引擎已购买或续费、以 `S_` 开头的 Speaker ID；系统不会自行生成或占用新的付费槽位。预付费槽位可在支持的声音复刻模型间复用。
- 训练音频统一转为 24kHz 单声道 WAV；ICL 2.0 建议使用 14–30 秒、单人、低噪声、情绪相对稳定的音频。训练请求固定使用 `seed-icl-2.0` 和 `model_type=4`。
- 试听和聊天合成使用 V3 HTTP 单向接口与 `seed-tts-2.0-expressive`，方言及管理端自由填写的补充指令通过 `context_texts` 传入；语速、音量由豆包原生参数完成，音调继续由平台 FFmpeg 输出层处理。
- 管理端可验证音色状态、重新训练同一 Speaker ID、生成试听并将豆包音色用于聊天和音色详情页自定义语音。重新训练必须沿用原槽位，不能静默切换到其他 Speaker ID。
- 删除管理端豆包音色只删除天之灵本地记录和绑定，不调用服务商的破坏性删除；付费槽位继续保留，可再次训练和复用。日志只记录脱敏 Speaker ID，不记录 API Key、Access Token 或完整音色标识。
- 生产环境优先使用新版 API Key。使用新版 API Key 时，训练请求中的 AppID 必须填写该 Key 所属项目自动生成的新版 APP ID，不能沿用旧版 `tianzhiling` 应用 APP ID；两者混用会返回 HTTP 403 `parameter license not found`。如账号训练权限仍要求旧版鉴权，才同时使用旧版应用的 AppID 与 Access Token。环境变量分别使用 `ADMIN_API_DOUBAO_VOICE_*` 和 `NODE_DOUBAO_VOICE_*`，Node 未单独配置时复用 Admin 配置。
- 管理端“音色管理”分为“音色”和“豆包槽位”两个视图。槽位视图通过火山引擎 `BatchListMegaTTSTrainStatus` OpenAPI 实时读取账户内固定资产，展示 Speaker ID、实例号、状态、到期时间、剩余训练次数，并按 Speaker ID 关联天之灵本地音色；不另建一份可能失真的槽位数据库。创建豆包音色时从空闲槽位下拉选择，已绑定、训练中、已固定、已到期、已回收或训练次数用完的槽位不能进入训练；OpenAPI 未配置时使用服务端明确配置的固定 Speaker ID 列表兼容。
- 豆包槽位以 Speaker ID 作为不可变身份，一个槽位只对应一个 Speaker ID。`ADMIN_API_DOUBAO_VOICE_KNOWN_SPEAKER_IDS` 按配置顺序固定已有槽位编号，OpenAPI 新发现但未配置的 Speaker ID 按购买时间追加展示；槽位列表只显示真实查询到或明确配置的 Speaker ID，不再根据容量补出没有 Speaker ID 的虚拟空槽，也不得在训练时自动生成 Speaker ID。
- 豆包槽位页只负责展示“槽位 / Speaker ID / 平台状态 / 本地音色”的资产占用关系和发起训练，不展示或修改智能体绑定。智能体与本地音色的绑定、解绑统一在音色或智能体管理入口完成，避免两个入口产生不一致状态。
- 槽位列表只在 Admin Node 配置火山引擎 OpenAPI AK/SK，使用 `ADMIN_API_DOUBAO_VOICE_OPENAPI_ACCESS_KEY_ID`、`ADMIN_API_DOUBAO_VOICE_OPENAPI_SECRET_ACCESS_KEY`、`ADMIN_API_DOUBAO_VOICE_OPENAPI_PROJECT_NAME` 等变量；AK/SK 不下发给 Admin Web 或 Node 聊天服务。
- 2026-08-26 真实联调：新版控制台 API Key 归属 APP ID `3486354884`；旧版 `tianzhiling` APP ID `9818056889` 不能与该 Key 混用。控制台开通“豆包声音复刻模型 2.0”API 服务后，候选代码对联调音色完成上传重训、状态查询、管理端预览和 Node 聊天合成闭环，供应商状态 `ready`、版本由 `V1` 更新为 `V2`。API Key 只注入运行环境，不写入仓库或联调记录。

## 二、当前用户流程

```text
进入声音服务
  -> 没有完成音色：直接开始/恢复训练流程
  -> 已有完成音色：声音模型入口进入“我的音色”；训练起点也可直接查看仓库
  -> 小使者介绍素材要求和免费训练规则
  -> collecting：从微信聊天选择文件或从手机相册选择，上传/删除多份素材，主动点击提交
  -> analyzing：后台识别、质量检测与剪辑，或整理用户已剪好的素材
  -> reviewing：查看提前排除原因，试听并选择“可以使用 / 再剪一下 / 不使用”；选中任意片段即可开始训练
       -> 再剪一下：填写时间要求 -> 单片段 queued/processing -> 成功后回到该片段重新试听选择
  -> training：合并已确认片段，创建 Qwen 声音模型
  -> preview_ready：播放试听音频
  -> completed：选择使用对象；有声音资格时直接接入，无资格时购买后自动接入
  -> 我的音色：保留全部已完成音色，可试听、改名、查看绑定或单独永久删除
       -> 音色信息：改名、关联天之灵、查看/下载训练片段，调整速度和音量，自定义文字生成语音
  -> 天之灵主页 -> 声音模型：选择账户内已完成音色；没有音色时进入训练；无声音版权益时保存为待生效
```

失败状态统一为 `failed`，用 `failureStage` 区分 `clipping` 和 `training`。剪辑失败保留素材；训练失败保留片段审核结果。

处理模式：

- `assisted`：百炼 Paraformer 识别、说话人分离和时间戳，按完整语句切片。
- `ready_to_use`：用户声明素材已经剪好，整份整理为一个候选片段。

## 三、业务记录与恢复要求

MongoDB 集合：`voice_service_session`。

实体：`packages/entities/src/voice-service-session.entity.ts`。

每条会话需要持续保存：

- `userId`、`status`、`processingMode`。
- `materials`：原文件名称、对象存储键、访问地址、时长、添加时间。
- `reviewClips`：来源素材、切片地址、时长、转写文字、说话人、质量分、声学指标、质量提醒、是否调高音量、审核结果、拒绝原因和审核时间；当前返工状态、要求、任务 ID、排队/处理/完成时间、失败码和失败原因；`recutHistory` 完整保存每次返工的原对象键哈希、原时长/转写、之前的审核决定、结果对象键哈希、结果时长和失败详情。
- `filteredClips`：未上传为审核音频的排除片段，保存来源素材、时长、转写文字、说话人、声学指标和排除原因，保证用户能看到且删除时能完整清理衍生内容。
- `messages`：用户问题和小使者回答，用于用户返回页面时恢复服务上下文。
- `events`：创建、添加/删除/提交素材、返回素材、片段就绪、片段审核、训练开始/完成/失败、选择天之灵、声音接入天之灵。
- `observability`：当前会话的排队时长、识别耗时、产出/过滤/自动调高/审核/采用片段数、采用率、训练次数与成功率，以及最后一个平台错误码。
- `processingAttempts`：按 `jobId` 保存每一轮剪辑和训练的入队、首个 Worker 开始、完成时间、结果、识别统计、片段统计和平台错误历史；重试不得覆盖旧轮次。
- `processingAttempts.residualAnalysisObjectKeys`：Paraformer 分析临时音频即时清理失败时保存对象键，整包删除继续重试。
- `dataDeletionStatus`、`dataDeletionRequestedAt`、`dataDeletionCompletedAt`、`dataDeletionFailures`、`pendingDeletionObjectKeys`：记录声音数据删除请求、部分失败和待重试对象。
- `deletedArtifactAudit`：保存已删除素材/切片的记录 ID、时长、片段审核决定和对象键哈希；不保存可播放 URL、真实对象键、文件名或转写内容。
- `clippingJobId`、`clippingStartedAt`、`clippingCompletedAt`。
- `trainingJobId`、`trainingAudioObjectKey`、`trainingStartedAt`、`trainingCompletedAt`。
- `voiceTimbreId`、`previewAudioUrl`、`previewAudioObjectKey`、`selectedAgentId`。
- `voiceAccessSource`、`voiceAccessReferenceId`、`voiceAccessVerifiedAt`：保存本次接入采用的权益证据，便于历史订单和后台记录追溯。
- `voiceBindingStatus`、`voiceBoundAgentIds`、`voiceBoundAt`：记录待购买、已接入或保留原后台声音，以及本次训练音色接入过的全部天之灵。
- `failureReason`、`failureStage`、`createdAt`、`updatedAt`。

恢复规则：

- 页面进入时调用当前会话接口，不按页面内存猜测阶段。
- `analyzing` 和 `training` 页面轮询任务状态；离开页面后后台任务继续执行。
- 未完成的后台任务可重新入队，但必须幂等。
- 剪辑和训练后台任务必须携带本轮 `clippingJobId` 或 `trainingJobId`；处理、成功发布和最终失败写入前都要重新读取当前会话，并确认状态和 jobId 仍匹配。旧一轮任务晚到时只能静默退出，不能覆盖新一轮流程。
- 整包删除先把会话切回 `collecting`、取消当前处理轮次并清空当前 jobId，再删除对象和模型。晚到的剪辑对象、训练音频、试听音频和音色必须立即补偿删除，不能重新挂回会话。
- 删除中或部分删除失败时禁止添加、重试上传和重新提交训练数据；用户重试删除成功后才允许开始新一轮。
- 单份素材只有在 COS 对象删除成功后才移除会话引用；失败时保留引用供用户重试。
- 返回素材后清空本轮 `reviewClips` 和剪辑任务字段，保留 `materials`、历史 `messages`、历史 `events`。
- 发布剪辑成功或失败前重新读取当前会话；只有仍处于 `analyzing` 才能写入，避免旧任务覆盖用户的新操作。
- 小程序上传素材时本地保留未完成队列：上传进度、失败原因、超大文件提示和本地临时路径。文件发完后显示“正在安全保存”，不把服务端 COS 保存阶段伪装成卡在 99%；上传期间“继续添加素材”保持可用，新增素材排队串行上传。上传请求允许最多等待 5 分钟，避免服务端已保存成功但客户端在 120 秒边界误判失败。页面重新进入时把未完成上传恢复为“上传中断，可重试”；如果微信临时文件已失效，提示用户重新选择素材。
- 新增状态、字段和事件时采用可选字段和追加枚举，不能破坏旧版小程序。
- 单片段返工复用声音剪辑队列，但使用独立 `recutJobId`。Worker 发布结果前必须再次确认会话仍为 `reviewing`、片段仍存在且任务 ID 匹配；用户返回素材、删除数据或再次返工后，晚到结果只能清理，不能覆盖当前片段。
- 单片段返工成功保存新片段后再清理旧切片；清理失败的对象键进入统一待删除记录。返工失败不得删除或改写原片段。

音色仓库使用 `voice_timbre` 集合，除原有模型和音频字段外持续保存：

- `userId`、`voiceServiceSessionId`：用户归属与来源会话；历史记录缺少 `userId` 时，通过来源会话或会话 `voiceTimbreId` 校验归属并兼容回填。
- `providerCreatedAt`、`providerLastUsedAt`、`providerEstimatedCleanupAt`：服务商创建、最近一次成功合成和按“一年未使用”估算的最早清理时间。
- `retentionStatus`、`retentionLastAttemptAt`、`retentionLastSucceededAt`、`retentionFailureCode`、`retentionFailureReason`：自动保活状态和失败详情。
- `trainingClipIds`：训练时实际选入合并音频的审核片段 ID。新训练直接写入；历史音色按当时“已采用片段 + 质量优先 + 最多 60 秒”规则兼容回填。
- `speechSpeed`、`speechVolume`：用户输出效果设置，默认均为 `1`；Qwen HTTP 合成后通过 FFmpeg `atempo` 和 `volume` 处理，也用于天之灵聊天语音。
- `generatedAudios`：自定义文本生成语音的文本、COS 对象键、生成时速度/音量和创建时间；用于详情页恢复、下载和完整删除。
- 自定义语音每日额度使用 Redis 北京日期键按用户计数，用户级生成锁覆盖额度检查、平台合成、COS 保存和业务记录保存，避免双击或多设备并发突破 5 次；请求失败回退预占次数。Redis 当日键首次建立时从该用户全部音色的 `generatedAudios` 兼容恢复已成功次数。
- `deletionStatus`、`providerDeletedAt`、`deletedAt`：用户单音色删除的可重试墓碑。仓库接口不返回其他用户、训练失败或已完成删除的音色。

天之灵使用 `agent` 集合保存声音选择：

- `voiceTimbreId`：当前实际用于聊天的音色，只在声音版权益有效时写入；旧版客户端和已有聊天逻辑继续读取该字段。
- `pendingVoiceTimbreId`：用户已经选择、但尚未取得声音版权益的音色；购买后再次进入天之灵主页时自动转为 `voiceTimbreId`。
- `voiceTimbreSelectedAt`：最近一次选择、启用或因权益变化转为待生效的时间。
- 删除音色或整包声音数据时，同时清理 `voiceTimbreId` 和 `pendingVoiceTimbreId`；不能只解绑已生效对象。

可观测性统计口径：

- 剪辑/训练排队时长：任务入队时间到本轮首个 Worker 开始处理的毫秒数；BullMQ 内部重试不重新计算。
- 识别耗时：本轮所有 Paraformer 调用的实际等待时间之和；同时保存识别素材数。`ready_to_use` 不调用识别，耗时为 0。
- 切出片段数：发布给用户审核的候选片段数。
- 过滤片段数：质量检测后未生成审核音频的候选片段数；自动调高片段数只统计实际发布给用户审核的修复片段。
- 用户采用率：`accepted / (accepted + rejected)`，待审核片段不进入分母；用户修改审核结果时实时重算。
- 训练成功率：`成功结束的用户训练轮次 / 已结束的用户训练轮次`；排队中、训练中和 BullMQ 内部重试不进入分母。
- 平台错误：每个处理轮次追加保存 `provider`、`operation`、原始 `code`、错误信息、平台请求 ID、HTTP 状态、Worker 尝试序号和发生时间。部分素材失败但整体成功时也保留错误。
- 结构化日志统一使用 `[voice-observability]` 前缀，包含会话 ID、排队/识别耗时、片段统计、采用率、训练成功率和最后错误码。

## 四、接口清单

控制器：`apps/node/src/controller/voice-service.controller.ts`。

- `GET /api/voice-services/current`：恢复当前会话。
- `POST /api/voice-services/start`：开始或继续训练。最新会话已完成时创建新的 `collecting` 会话；其他未完成状态返回原会话。
- `GET /api/voice-services/timbres`：读取当前用户的已完成音色仓库和服务商保留规则；兼容回填历史音色归属。
- `GET /api/voice-services/timbres/:timbreId`：读取当前用户的音色详情、实际训练片段、合并训练音频、输出设置和已生成语音。
- `PATCH /api/voice-services/timbres/:timbreId`：修改当前用户的音色名称、说话速度或音量；字段均可选，但至少提交一项。
- `POST /api/voice-services/timbres/:timbreId/speech`：用当前 Qwen 音色和输出设置把最多 100 字自定义文本生成语音，保存到 COS 并记录到音色详情；当前用户全部音色合计每天最多成功生成 5 次。
- `DELETE /api/voice-services/timbres/:timbreId`：永久删除单个音色、训练音频、试听音频和自定义生成语音并解除绑定；原素材和审核切片不随此接口删除，部分失败可再次调用重试。
- `GET /api/voice-services/agents/:agentId/timbres`：读取属于当前用户的天之灵及当前账户音色，返回已选、已生效、待会员生效和声音版权益状态；权益恢复时自动启用之前的待生效选择。
- `PATCH /api/voice-services/agents/:agentId/timbre`：为属于当前用户的天之灵选择已完成音色。替换其他已生效或待生效音色时必须传 `replaceExisting=true`；无声音版权益时只写待生效字段。
- `POST /api/voice-services/materials`：保存一批已上传素材。
- `DELETE /api/voice-services/:sessionId/materials/:materialId`：删除素材。
- `DELETE /api/voice-services/:sessionId/data`：永久删除当前会话的全部声音实物数据和平台声音模型；部分失败返回 `dataDeletionStatus=partial_failed`，再次调用同一接口重试。
- `POST /api/voice-services/:sessionId/submit`：用户确认全部上传完毕，选择处理模式并开始后台任务。
- `POST /api/voice-services/:sessionId/back-to-materials`：从剪辑或审核返回素材准备。
- `POST /api/voice-services/:sessionId/back-to-review`：训练中、训练失败后或试听确认前返回片段选择；保留切片和审核决定。运行中的训练代次会取消，旧任务晚到时丢弃并清理其模型；已经生成的试听模型会先进入补偿清理。
- 小程序流程内的“返回上一步”点击后直接执行并原位显示加载状态，不再经过确认弹窗；从剪辑/审核返回时保留原素材，从训练/试听返回时保留切片和审核决定。
- `POST /api/voice-services/messages`：无会话时咨询小使者。
- `POST /api/voice-services/:sessionId/messages`：会话内咨询小使者。
- `PATCH /api/voice-services/:sessionId/clips/:clipId`：提交片段审核结果。
- `POST /api/voice-services/:sessionId/clips/:clipId/recut`：填写具体剪法并启动该片段的独立返工任务；入队前校验时间描述。
- `POST /api/voice-services/:sessionId/train`：使用已确认片段开始免费训练；可选传入 `agentId`，服务端校验归属后保存该天之灵对用户的真实称呼，用于合成个性化试听句。
- `PATCH /api/voice-services/:sessionId/agent`：试听后选择使用对象，不在这里收费。

小程序 API：`apps/weapp/src/apis/voice-service.ts`。

聊天语音转换接口：

- `POST /api/conversation/:conversationId/messages/:messageId/voice`：把 AI 文字回复转为语音；已有保存音频时只切换展示，不重复合成。

## 六、当前剪辑与训练策略

AI 模式：

1. 从音频或视频提取分析音轨。
2. 使用 Paraformer 获取句子时间戳和说话人编号。
3. 合并同一说话人的相邻完整语句，按时间戳切片。
4. 在响度统一前生成单声道 24kHz 候选 WAV，检测实际时长、静音占比、RMS/峰值音量、削波占比、底噪和估算信噪比。
5. 明显不可用的候选写入 `filteredClips`，不上传可播放切片；即使全部候选被过滤，会话也进入 `reviewing`，让用户查看原因并返回补素材。
6. 可恢复的低音量候选先按上限增益，再使用 `afftdn`、`adeclick` 和 `loudnorm` 生成审核 MP3；`qualityMetrics.volumeAdjusted` 和 `volumeGainDb` 记录修复事实。
7. 切片时只保留很短的前后余量，减少相邻通知音进入。
8. 没有可靠转写时不再退回固定时间切片，避免把电子音当成人声发布给用户。
9. 电子音与人声完全重叠、持续人声没有可供估算底噪的停顿时，自动判断仍有限，因此所有保留片段必须让用户试听审核。

单片段返工：

1. 当前支持“去掉开头/结尾 N 秒”“只保留前/后 N 秒”“只保留 A 秒到 B 秒”“从 A 秒开始/到 B 秒结束”，兼容阿拉伯数字、常见中文数字和 `mm:ss`。
2. 用户提交时先把描述解析为当前片段内的起止时间，至少保留 2 秒；无法解析或范围无效时立即返回可理解原因，不进入队列。
3. Worker 只下载当前审核片段并精确裁切，不重新处理全部原素材；裁切结果重新执行同一套声学质量门禁并上传为新的审核 MP3。
4. 成功后片段 ID 和原列表位置不变，替换播放地址、时长和质量结果，审核状态回到 `pending`；失败时原对象、原播放地址和待确认状态保持不变。

质量门槛默认值：

- 时长不足 2 秒：排除。
- 静音占比超过 75%：排除；达到 45%：保留并提醒。
- 削波占比超过 12%：排除；达到 1%：保留并提醒。
- RMS 低于 `-58 dB`：视为无法可靠恢复并排除；处于 `-58 dB` 到 `-32 dB`：目标调至约 `-22 dB`，单次最多增加 20 dB。
- 片段存在至少 2% 可识别停顿时才判断背景噪声。底噪高于 `-35 dB` 且估算信噪比低于 4 dB：排除；底噪高于 `-45 dB` 且估算信噪比低于 12 dB：保留并提醒。
- 背景噪声是 FFmpeg 声学启发式估算，不等同于人工听感或语音增强模型评分；正式素材回归后应继续校准，不能作为唯一训练质量保证。

对应配置均为可选环境变量，旧环境不配置时使用上述默认值：

- `NODE_VOICE_CLIP_MIN_USABLE_SECONDS`
- `NODE_VOICE_CLIP_MAX_SILENCE_RATIO`
- `NODE_VOICE_CLIP_MAX_CLIPPING_RATIO`
- `NODE_VOICE_CLIP_MIN_RECOVERABLE_RMS_DB`
- `NODE_VOICE_CLIP_LOW_VOLUME_RMS_DB`
- `NODE_VOICE_CLIP_TARGET_RMS_DB`
- `NODE_VOICE_CLIP_MAX_VOLUME_GAIN_DB`
- `NODE_VOICE_CLIP_MIN_SIGNAL_TO_NOISE_DB`
- `NODE_VOICE_CLIP_WARNING_SIGNAL_TO_NOISE_DB`

训练模式：

1. 只读取 `accepted` 片段。
2. 下载并合并为单个 WAV，片段之间加入短静音。
3. 当前最多选取约 60 秒训练内容；超过时按质量分优先选择，并保持入选片段原有顺序。Qwen3-TTS-VC 官方建议复刻音频为 10–20 秒，最长 60 秒，因此 1 分钟是上限而不是必须凑满的目标。
4. 合并音频保存到 `voice-training-ready`。
5. 创建 `VoiceTimbreEntity`，调用 Qwen voice enrollment。
6. Qwen 创建成功后立即保存真实平台音色 ID，再生成试听，避免试听失败时留下无法追踪的平台模型。
7. 用固定试听文案生成预览，同时保存预览地址和 COS 对象键并把音色状态改为可用。
8. 任何平台错误写入音色错误码和错误信息，同时保留会话重试所需记录。

音色保留模式：

1. Qwen-TTS 音色默认长期有效，但连续一年没有用于任何语音合成请求时服务商会自动清理；页面上的时间是按最近成功合成估算的最早清理时间，不承诺服务商精确执行时刻。
2. 每次训练试听和天之灵真实语音合成成功后，更新 `providerLastUsedAt` 并把预计清理时间顺延一年；记录时间失败不能丢弃已经生成的用户语音。
3. 每日 BullMQ 保活任务筛选距离预计清理时间不足 30 天的用户 Qwen 音色，每批最多处理 25 个，以固定短文本发起一次合成；成功后顺延一年，失败记录平台错误并在后续轮次重试。
4. 服务商 1000 个是百炼平台账号级 Qwen-TTS 配额，不是每用户 1000 个。官方当前没有公开的付费存储提额套餐；`0.01 元/个`是创建费用，控制台限流提额是 TPM 等调用速率，均不会提高音色存储上限。达到上限不会覆盖用户已有音色；应监控账号总量并优先处理已删除墓碑、无归属异常和保活失败音色，不能静默删除有效用户音色。超过 1000 的企业需求只能提前通过阿里云客户经理或工单确认特殊配额，不能把未获批的提额作为容量方案。
5. 自动保活会产生极少量语音合成调用成本，由平台承担，不向用户单独计费。Qwen-TTS 音色创建的服务商计费和免费额度属于平台运营成本，产品仍保持“声音训练免费”。

删除模式：

1. 单份素材使用 COS `DeleteObject` 物理删除，成功后再删会话引用。
2. 整包删除收集原素材、残留分析音频、审核切片、训练音频、试听音频和该音色自定义生成语音的对象键，按键去重删除。
3. Qwen 音色通过 customization 接口的 `qwen-voice-enrollment`、`action: delete` 删除；成功后音色记录改为禁用墓碑，清除真实平台 ID 和音频引用。
4. 查找所有绑定该音色的天之灵并解除 `voiceTimbreId`，不只处理会话当前选择的对象。
5. 成功删除的引用立即清空；失败对象、平台错误码和原因保留，状态设为 `partial_failed`，同一接口可幂等重试。

## 七、小使者交互约定

- 首次进入：只强调各种留有他声音的素材都可以直接发来，音频、视频均可，用户不用提前剪辑或整理，小使者会帮助处理。不要在首屏主动讲解具体选择入口和录屏步骤。
- 素材导入：点击添加按钮后提供“从微信聊天选择文件”和“从手机相册选择”两个入口。用户主动询问微信语音时，再说明原生语音消息不能直接导入，需要先播放并录屏，然后从手机相册选择录屏视频。
- 有素材：明确“已经保存好”，提醒传完后再提交。
- 素材仍在上传或显示“正在安全保存”时，“智能识别并剪辑”保持可点击；点击后提示等待当前素材上传并保存完成，不得静默无响应，也不得只提交已经保存的部分素材。
- 分析中：说明正在区分说话人、整理完整语句，预计两到三分钟。
- 审核中：说明只有用户确认的片段才会用于训练，并显示已选时长和 1 分钟上限；选中第一段后立即在已选时长下方只显示一个“开始训练”按钮，不再重复展示已选片段数、时长和解释文字，也不要求把其余片段逐一处理完。声音参数不直接展示静音百分比、dB、底噪或信噪等工程指标，只保留时长、清晰度和用户能理解的质量提醒；切片页不显示识别转写文字，过滤片段只显示来源和简化后的具体排除原因。点击试听时先显示音频下载百分比，开始播放后显示当前时间、总时长和连续播放进度。
- 再剪一下：弹窗只要求填写剪法并给出时间写法示例。提交后片段原位显示要求和处理中状态；页面保持轮询，成功或失败后自动滚回该片段。处理中、完成和失败提示均使用子包预置固定语音。
- 训练中：说明正在合并已确认声音并免费生成模型，同时提供“返回上一步”。确认返回后停止采用当前训练结果，回到片段选择；已剪片段和用户选择必须保留。
- 试听：先试听，再选择使用对象。
- 试听未确认：允许返回上一步重新选择片段；当前试听模型移除，原始素材、切片和审核决定保留。页面同时提示“大模型厂家限制、暂存 7 天、未使用会自动清理”。已经完成接入的音色不在原会话中回退，需从音色仓库管理或重新开始一次训练。
- 选择使用对象：已有声音资格时明确“选择后直接接入”；无资格时说明购买后自动接入。原来已有后台声音时说明已经保留，不让用户误以为被替换。
- 失败：告诉用户哪些记录仍被保留，以及可以重试还是需要补充素材。
- 删除：页面底部提供独立的危险操作，确认框完整列出删除范围和不可恢复性；部分失败时原位显示原因和“重试删除”。
- 音色仓库：“我的 -> 声音模型”先进入仓库，直接展示已完成音色、试听、绑定对象和保留状态；保留规则默认只显示一句简短说明，用户点击后再查看服务商、一年未使用清理、平台账号上限和主动删除后果。
- 声音模型入口：仓库接口返回 0 个完成音色时立即替换页面进入训练流程，不展示“0 个音色”、保留规则或空仓库按钮。已有音色的仓库只显示简洁概览和音色列表；整卡进入详情，卡片只保留试听与更多管理，改名和永久删除收进更多菜单。
- 训练起点：已有完成音色时，在素材区上方显示“我的音色”入口和数量；没有完成音色时不显示该入口。训练页首次进入调用开始接口，已完成会话自动开启新的素材准备，未完成会话继续恢复。
- 音色信息：点击整张音色进入。身份区不展示声音技术服务商，名称可直接编辑；“关联天之灵”列出当前账户拥有的天之灵并区分聊天中使用和待声音版会员生效。训练片段保持简洁，只显示名称、来源、时长和可理解的转写；每段可试听和下载。速度与音量用滑杆调整，保存后同时作用于自定义生成和聊天语音；自定义文本每次最多 100 字，页面显示今天剩余次数，生成后自动试听并保留下载入口。每天 5 次用完后禁用生成按钮，并明确提示明天继续。
- 天之灵主页声音模型：仅所有者可见。点击后列出当前账户已经训练完成的音色；没有音色时用确认提示进入声音训练。选择器固定提示“必须购买声音版会员，所选音色才会在聊天对话中生效”，无权益时可先选择并从按钮进入声音版会员页。
- 固定阶段文案统一维护在 `voice-service-prompts.json`，对应 MP3 随声音训练子包发布并直接播放；不得在页面打开时预热或请求生成。动态问答可以实时生成，前端语音请求和下载均设短超时，文字和按钮不等待语音。固定音频更新时运行 `pnpm --filter weapp generate:voice-prompts`，并随文案一起提交。

## 八、价格和付费逻辑

- 训练声音模型本身免费，不在训练前卖套餐。
- 实际使用声音能力时再提示会员权益。
- 小使者回答价格问题时读取当前有效年付计划，不把历史价格写死在人格提示中。
- 介绍无声音服务和含声音服务两个层级，并提醒以会员服务页最新价格为准。
- 选择天之灵不扣费。已有历史声音资格时直接接入训练音色；尚无资格时先保存使用对象，购买声音版会员后再次进入页面自动接入。
- 声音资格是用户级兼容权益，不消耗 `voice_model` 次数，也不要求旧声音订单必须已有训练任务。订单状态为退款或关闭时不能作为新接入依据。
- 管理端可把已完成的普通微信支付声音版会员降为同周期基础版。退款金额取“声音版与目标基础版的套餐价差”和“该订单实付金额”中的较小值，兼容直接购买声音版和补差升级声音版两种订单；微信退款成功后保留会员起止时间，切换会员计划，回收该订单不再包含的权益，并解除由该订单建立的声音接入。训练素材、音色模型和业务记录不删除。
- 降级使用独立的 `voiceMembershipDowngrade` 订单快照记录原计划、目标计划、退款金额、退款单号、微信状态、操作账号和处理时间。原订单继续保持 `completed`，不得伪装成整单退款；退款处理中不提前修改会员，退款成功但权益处理失败时允许管理端刷新并幂等重试。
- 声音资格解析只读取现有会员、订单、权益、旧训练任务和绑定记录，不修改管理端订单履约或已经接好的后台声音服务。

## 十、当前已知问题和后续优先级

P0：

1. 使用真实微信录屏、多人视频、电子提示音、背景音乐、方言和弱网素材做回归测试。
2. 验证正式测试环境的 FFmpeg、BullMQ Worker、COS、Paraformer 和 Qwen 配置及权限。
3. 用真实平台完整跑通“多个确认片段 -> 单个训练音频 -> 音色创建 -> 试听”。
4. 清理或重新处理历史固定时间切片；旧切片不会因新策略自动改善。
5. 在正式测试环境验证 COS 删除权限、Qwen 音色删除权限，以及平台已删除/对象不存在时的幂等响应。
6. 在正式环境验证音色保活重复任务只注册一次、Qwen 短文本合成能重置服务商未使用周期，并为账号级音色数量、保活失败和接近 1000 上限建立告警；在达到 800 个前确认阿里云特殊配额或多账号/多服务商容量方案。

P1：

1. 把多人素材按说话人分组，让用户先确认哪一组是他的声音，再审核组内片段。
2. 使用真实用户素材校准当前质量门槛，并评估是否引入专用语音质量或降噪模型补足持续背景噪声识别。
3. 如后续真实弱网仍不稳定，再评估分片上传、后台续传和服务端合并。
4. 增加服务商音色列表的定期对账，识别平台已自动清理但本地仍标记可用的异常记录，并设计基于保留训练音频的恢复流程。
