# T3：复读守卫 L1/L2 分层

## 问题

守卫收窄后，回放显示第 3 轮重复第 2 轮的问题（同义换词复读，字面不同但语义相同）。旧守卫的"完全相同才删"抓不到这种换词复读。

## 方案

在 `apps/node/src/service/agents/reply-repetition-guard.ts` 中，将重复检测分为两层：

```text
L1 字面层（保守）：
  整段 normalized equality（去空白/标点后逐字相同）
  → 删除该段

L2 问句层（新增）：
  判据 = 问句意图 + 对象 + 时间/事件槽位
  简化实现：检查回复是否为问句（含 ?/？）且与最近 N 轮助手消息的问题主题重合
  主题重合判定：两问句的"实词交集"占较短问句 60% 以上
  → 抑制（换陈述或体面放下）

保留条件（不抑制）：
  包含旧词 + 新解释/纠正/新信息 → 保留
  整段是旧问句变体 + 无新信息 → 抑制
```

## 实现

1. 在 `reply-repetition-guard.ts` 中新增 `isSameQuestionIdentity(a: string, b: string): boolean`：
   - 两句都是问句（含 ?/？）
   - 两句实词交集 / 较短句实词数 ≥ 0.6
   - 不引入新关键词表
2. 在现有守卫逻辑中调用：L1 保留现有逻辑，L2 新增调用
3. 审计字段：`replyGuardrailReason` 标注 `repeated_generic_move[L2]` vs `[L1]`
4. 测试：
   - "是不是又想我了？" → "是不是又想我啦？" → L2 抑制
   - "又想我了，对吧？" → L2 抑制
   - "我想说说昨天你说的" → 保留（有新信息）
   - "你刚才说的'想我了'，我想说说这个" → 保留（引用+新内容）
   - 原事故四轮回放：零复读

## 边界

- 只改守卫判定，不加关键词表
- 不影响 T1/T2/T4/T5 已上线的内容
- 不引入新的持久状态
