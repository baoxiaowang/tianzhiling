# 人脸识别阈值标定报告（合成数据基线）

- 日期：2026-11-02
- 数据：randomuser.me 公开合成人像 **22 人**（AI 生成，不含真人隐私）
- 每个人 4 张变体（原图 / 缩放 / 亮度 / 裁剪 / 翻转）→ 同人 86 对，跨人 231 对
- 模型：dlib ResNet（face_recognition），128 维，欧氏距离

## 一、距离分布

| 指标 | 同人（genuine） | 不同人（impostor） |
| --- | --- | --- |
| 均值 | **0.097** | **0.806** |
| P95 / P5 | 0.214 | 0.653 |
| 极值 | max 0.257 | min **0.515** |

两类分布**完全分离**（同人最大 0.257 < 跨人最小 0.515），中间有约 0.26 的安全间隔。

## 二、阈值扫描（节选）

| 阈值 | FAR（误接受） | FRR（误拒绝） |
| --- | --- | --- |
| 0.34～0.50 | **0.00%** | **0.00%** |
| 0.56 | 0.00% | 0.00% |
| 0.60 | 2.16% | 0.00% |
| 0.70 | 12.99% | 0.00% |

## 三、建议阈值

| 档位 | 建议值 | 依据 |
| --- | --- | --- |
| 确认（confirmed） | **0.56**（合成数据下 FAR ≤ 0.5%） | 同人 max 0.257，跨人 min 0.515 |
| 反问（ask） | **0.64**（FAR ≤ 5%） | 覆盖质量较差/角度偏的探针 |
| 当前默认 | 0.45 / 0.60 | 更保守，合成数据下 FAR=0 |

## 四、小库决策模拟（8 人库、86 个探针）

| 结果 | 数量 |
| --- | --- |
| 确认正确 | 32 |
| **确认错误（误认）** | **0** |
| 反问 | 9 |
| 不认识（含非库内人员） | 45 |

**关键结论：在可分离的数据上，三档策略没有产生一次误认**；45 个"不认识"里包含 14 位不在 8 人库内的探针（本就应判未知）。

## 五、局限与下一步

1. 合成数据是"同一张脸做轻度变换"，**难度显著低于**真人老照片（不同年代、光线、妆容、模糊）；
2. 因此本报告只能作为**下限参考**，证明"当前默认阈值不会盲目误认"；
3. 最终阈值必须用业务真实照片复标（`face:eval` 脚本已就绪，等待授权读取生产照片）。

## 六、复现方式

```bash
# 1) 下载人像到 /tmp/face-eval/raw/（men_1.jpg … women_12.jpg）
# 2) 拷进 sidecar 容器并执行
docker cp /tmp/face-eval tzl_face_sidecar:/tmp/face-eval
docker exec tzl_face_sidecar python3 /app/tools/threshold_eval.py
```
