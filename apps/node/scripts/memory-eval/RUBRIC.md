# 记忆质量评分标准（冻结 v1）

本文件是评分标准本身。**评测代理只允许依据本文件判定，不得参考任何历史结论、修复说明或优化者自述。**

## 一、逐条判定

对每条被保存的记忆，独立判定为以下之一：

- **应保留（keep）**：用户明确陈述的、未来对话确实需要的稳定事实。例如：身份、亲属关系、稳定偏好、明确的经历、明确说出的重要处境。
- **应降级（downgrade）**：真实但只是当下的情绪或临时状态，只能作为短期/不可断言信息。例如："难受""好累""想你""不开心""敏感"。
- **应丢弃（drop）**：不属于事实的内容。包括：
  - 从一个词或短句推断出的心理结论（如"体现自我保护""沉默式承认""隐含反讽"）；
  - 客套或空泛回应（"挺好的""他们好得很""嗯"）；
  - 亲属称谓写错（把"太太"写成"母亲"等）；
  - 与已有条目近义重复的碎片。

判定必须写出理由，并引用对应原话片段。

## 二、指标（由评测代理逐条判定后确定性汇总）

| 指标 | 定义 | 门槛 |
| --- | --- | --- |
| 稳定事实命中率 | 被"应保留"且确实存在的稳定事实数 ÷ 独立通读原话后认定的稳定事实总数 | ≥ 0.80 |
| 情绪当事实率 | 被判为 downgrade 或 drop 的条数 ÷ 总条数 | ≤ 0.15 |
| 称谓错误率 | 人物称谓写错的条数 ÷ 涉及人物的条数 | = 0 |
| 重复率 | 近义重复条数 ÷ 总条数 | ≤ 0.15 |

## 三、独立性要求

1. 评测代理不得读取优化者的代码改动说明、历史报告或前几轮结论。
2. 评测代理必须先独立通读原始消息，列出"应当记住的稳定事实"作为金标，再去看系统保存了什么。
3. 复评必须由**非诊断者、非修复者**的另一个代理完成。
4. 评测集与门槛在本版内冻结；如需变更，必须新建 version。
5. 指标汇总尽量用脚本确定性计算；代理只负责逐条判定与金标。

## 四、通过条件

- 四项指标全部达门槛；且
- 相对上一轮基线，任一指标不得恶化。
