# 记忆质量评分标准（v2）

> v1 已冻结留存：`RUBRIC-v1-frozen.md`。
> v2 的改动来自一次两轮一次的高层对照分析：v1 的四项比率**已经失灵**（口径不可复现、
> 可被"少记/聚合"刷过、且完全没有覆盖人物身份与时间精度），因此降级为**下限告警**，
> 并新增五个主维度。

## 零、判定前必须先做的一件事

评测任何用户之前，先只读 `messages` 产出并冻结两张表：

1. **金标人物表**：用户提到过的每一位亲属 —— `{name, aliases[], relationToUser, alive}`。
2. **金标事实表**：应当被记住的稳定事实（同 v1），每条标注主体与时间性质。

没有这两张表的轮次**视为无效轮次**，不得用于任何趋势或对照结论。
（历史教训：t1/t2 两轮 30 个用户没有金标、没有台账，事后无法复评，只能整轮作废。）

## 一、硬错误（必须为 0，任一不为 0 即整轮不通过）

| 硬错误 | 定义 |
| --- | --- |
| 身份矛盾 | 同一个人被写成两个不同身份/关系（"傅英傑既是丈夫又是儿子"、"张地既是女儿又是配偶"） |
| 称谓错误 | 亲属称谓写错，或称谓不是相对**用户本人**（"爷爷的姐姐"当作用户的核心亲属） |
| 主体挂错 | 某位亲属的属性挂在用户或 AI 角色身上（"妹妹已长大成人"记在用户名下） |
| 凭空捏造 | 写出了用户原话里不存在的人、关系或状态 |
| **伪造精确度** | 用户只给了模糊时长/时点，却写出精确年月日 |

## 二、五个主维度

| 维度 | 怎么判定 | 门槛 |
| --- | --- | --- |
| 人物实体唯一性 | 1 −（矛盾/重复身份数 ÷ 金标人物数）；同一人的多种叫法必须归并为别名 | ≥0.95 |
| 人物建档完整度 | 金标人物表中有正式实体的人数 ÷ 金标人物数 | ≥0.60 |
| 时间可回溯与精度忠实 | (a) 用户明说的时长/时点落成可回溯断言的比例；(b) 伪造精确度条数 | (a) ≥0.70；(b) =0 |
| 主体归属正确率 | 1 −（挂错主体的条数 ÷ 涉人条数） | ≥0.95 |
| 原子性与可纠正性 | 单条只回答一个实体一个属性（一条装 ≥3 个亲属即不合格）；用户更正后旧值被覆盖而非并存 | 聚合条数占比 ≤0.10 |

## 三、下限告警（v1 的四项比率，降级为告警，不作为通过条件）

| 指标 | 定义 | 告警线 |
| --- | --- | --- |
| 稳定事实命中率 | 命中数 ÷ 金标事实数。**命中必须是"单实体、单属性、可检索"的一条**；聚合值（一条 key 装多个亲属或多个属性）不得一票命中多条 | <0.80 告警 |
| 情绪越权率 | 情绪/心理类条目中被标为 `can_assert` **且** `durable` 的比例（合理的情绪记录必须 `context_only`/`session`，不计入） | >0.15 告警 |
| 称谓/主体错误率 | 见"硬错误"中的称谓错误与主体挂错 | >0 告警 |
| 重复率 | 近义重复条数 ÷ 总条数 | >0.15 告警 |

> 口径说明：v1 的"情绪当事实率 =（downgrade+drop）÷ 总数"被废弃 —— 它把"情绪""捏造""重复"
> 混成一个数，且与重复率重复计数，同一份标准在不同代理手里得出相反结论（一处 23/24 达标、
> 一处 0/6 达标）。

## 四、通读验收（唯一直接对应"更像这个人"的检查）

把该用户的 `facts` 交给一个**没读过原文**的新代理，让它回答三个问题：
这家有谁？最近发生了什么？这个人最在意什么？

- 3 分：三个问题都能答对且不编造
- 0 分：答不出，或答错亲属关系
- 门槛：≥2 分

**通读结论与数字冲突时，以通读为准**，并把冲突写入观察项。

## 五、通过条件（v2）

一轮通过 = 硬错误全为 0 **且** 五个主维度全部达标 **且** 通读验收 ≥2 分。
下限告警只用于提示，不作为通过条件；但告警项恶化必须在轮末复盘中给出解释。

## 六、独立性

1. 诊断、复评、复盘由**不同代理**完成。
2. 金标与金标人物表按用户冻结；复评若认为有误只写 `gold-proposal-*`，并同时用冻结版给出结果。
3. 指标由脚本确定性汇总；代理只做逐条判定与金标。
4. 每批必须留下 `gold-<runId>-<userId>.json` 与 `batch-ledger.jsonl` 记录，缺一即该批作废。
5. 跨用户、跨批次的数值差异**不得**作为程序变好/变坏的证据；只有同用户 + 同冻结金标的前后对照才算。
